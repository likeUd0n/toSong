# Suno 作曲・作詞メソッド

Suno AI で楽曲を制作する際の普遍的な設計原則・作詞ルール・タグ／パラメータ仕様をまとめた共通メソッド。

---

## 1. 基本設計・世界観（ペルソナと視点）

### 曲調の軸とギャップ対比
- **ストレート寄り添い vs ギャップ対比**: 曲のテーマに合わせて軸を決める。
- **ギャップ対比の原則**: 歌詞のテーマが暗く重い（辛い・孤独など）ほど、曲調は悲壮感ゼロの明るさ・祝祭感で作り切ることで強烈なコントラストを生む（例：キラキラしたピアノ＋鈴・チェレスタ等のアップテンポポップ）。

### 歌い手（ペルソナ）の設計
曲を作る前に、主人公のペルソナを別ファイル（`ペルソナ.md`）に詳細に定義し、そこから逆算して歌詞・声質・場面を構成する。
- **基本情報**: 年齢、性別、職業、家族構成など
- **嗜好・SNS**: 好きなコンテンツ、好きなもの／嫌いなもの、普段の振る舞い
- **内面・背景**: 外に見せる自分（強がり・役割）と内側の本音（弱さ・願い）、この曲を歌う背景になった出来事
- **共感要素**: 周囲との比較、恋愛や人間関係のすれ違いなど、リスナーが「自分のことだ」と重ねられる要素を入れる

### 舞台設定・伏線と回収
1. **最初に「曲の舞台」を設定する**
   - 1番と2番で場面が唐突に飛び、リスナーが置いてけぼりにならないよう、冒頭で場所と登場人物を提示する。
2. **伏線と回収（抽象・取り繕い → 具体・本音）**
   - 1番は聞こえの良い言葉や日常風景で取り繕いながら、2番で出てくる人物や背景の伏線をサラッと置いておく。
   - **伏線は「置いて終わり」にしない**: 1番に出した要素（物・通知・セリフ）は、後半でどう繋がり反転するかを設計してから配置する。因果関係が見えない要素は入れない。
   - **2番はシーンと焦点を絞る**: 短い文字数に複数の人物や場面を詰め込むと情景が浮かばなくなる。背景を明かすときは「1つの場面・1人の相手・具体的な動作」に絞って映像を見せる。
3. **コア名詞の制限（4〜5個）とサビ末尾の回収**
   - 単発の名詞を並べる「モノの展示会」を避け、コア名詞を4〜5個に絞って関係値（対比・因果・心情投射）を濃くする。
   - サビ末尾は抽象的な感想で終えず、「アクション後のモノの見え方の変化（客観描写）」で伏線を回収して着地する。
4. **視点の一貫性と Cメロでの意図的な味変**
   - Aメロ〜1サビに二人称の「先生視点（説教・教訓）」を唐突に混ぜず、一人称の独白パートでは視点の一貫性を保つ。
   - **Cメロ（Bridge）に限っては**、「他者の声（外圧）の引用」や「もう一人の自分への強い呼びかけ・命令形」へ意図的に切り替える（語り手の味変）ことで、メリハリとラスサビへの推進力を生む。

## 2. 作詞ルール（トーン・リズム・日本語表現）

1. **感情トーンの統一（「カラッとした自虐」vs「ヒステリック」）**
   - 暗い本音は、大仰に重々しく溜めるのではなく、**鼻歌や世間話のついでにポンッと乗せるエッセンス**として扱う（ギャップ曲の場合）。
   - **トゲのあるヒステリックな拗ねを混ぜない**: 明るく痛々しい自虐（良い例：`笑顔のままで ため息を隠す`）を軸にする場合、急に攻撃的・ヒステリックな皮肉（悪い例：`はいはい、ワガママでごめんなさいね`）を入れると主人公の芯がブレるため避ける。
2. **言葉のにごり・口語・端的表現**
   - 硬い書き言葉は自然な話し言葉にし、説明を減らす。設定書の解説語（「都合のいい笑顔」など）をそのまま貼らず、具体的なモノや行動（スタンプをすぐ返す等）に預ける。
   - 綺麗に整えすぎず、あえて言い淀み（`あ、いや`）、崩した口語（`〜とか` `〜んでしょ`）、字余りなどの「にごり」を入れて人間らしいグルーヴを作る。
   - **詩的・端的な対比フレーズ**: 説明を省き、短いフレーズに鋭い対比（例：`冷めたコーヒー / 熱すぎる強がり`）を凝縮する。
3. **直訳的な名詞・ねじれた背景描写の回避**
   - 画像の見た目を直訳した不自然な言い回し（例：`銀のリング`、`オレンジのライトの輪の中`）や、文字数圧縮で主語となるモノを落とした描写（例：`0時15分がそっと光る`）は避け、日常の日本語・動詞を含む自然な情景（`指輪`、`明かりの下`、`画面の0時15分が灯る` 等）に直す。
4. **母音の固定（ライム）と音数・ブレス設計**
   - 行末やフレーズ単位で母音（`a→a`, `u→u`, `e→e`, `i→i`, `o→o`）を揃え、聴覚的な気持ちよさを作る。
   - 170 BPM 超のアップテンポでは1行の音数を揃え（例：Aメロ15〜17音、Bメロ前半12〜14音）、ブレスの隙間を作る。
   - 文節と異なる位置にあえて半角スペースを入れる「空白ズラし」で、溜めやグルーヴを作る。
   - Pre-Chorus や Bridge の終わりは、カウントや短い音節の連打・クラップでビートを際立たせてからサビへ飛び込む。

## 3. 編曲・セクション展開と Suno メタタグ

1. **イントロとアウトロの額縁構造（空気感の統一）**
   - イントロで提示した空気感・モチーフ楽器（例：チェレスタ／ウインドチャイム）を、サビでも `[Reprise Celesta Motif]` 等で再登場させ、アウトロでは `[Sudden Silence]` でカットアウトした後に同じ単音モチーフを残す（`suddenly fade out` のような矛盾表現は避ける）。
2. **Aメロの2行刻みレイヤリング**
   - 4行単位でのっぺりさせず、2行ごとに少しずつビート要素（`[Add Soft Kick]` → `[Add Soft Bass]` 等）を追加して推進力を出す。
3. **Bメロの V字コントラスト（引き算と止まり）**
   - Bメロに `[Build-up]` を置くと騒がしくなりがち。`[Half-time]` `[Sparse Piano]` で一度音を落とし、サビ直前に `[Break]` を挟んでから、1サビを `[Full Band]` `[Explosive Chorus]` で解放する（1サビに `[Light Rhythm]` を置くとBメロに負けるため避ける）。
4. **セクション間のビルドアップ分離と高域の交通整理**
   - Pre-Chorus と Bridge で同じビルドアップ手法（ティンパニ連打等）を重ねない（例：Pre-Chorus は4つ打ち＋クラップで軽快に助走し、Bridge で初めてティンパニやライザーを使う）。
   - 1サビと大サビ（転調後）で高域楽器を整理する（例：1サビはピアノ＋フルート主役でブラス抜き、大サビで初めてブラスや分厚いストリングスを解禁して音圧の段差を作る）。
5. **絶妙な「一拍の間（ブレイク）」**
   - 作り笑顔が引きつる瞬間や本音が零れた直後の静寂として `[One-Beat Break]` / `[One-Beat Silence]` を配置する。
6. **メタタグの記法ルール**
   - **1〜3語・名詞ベースの標準英語キーワードに限定**: Suno が歌詞と誤認して歌い出す（Hallucination）のを防ぐため、`Sudden warm burst:` のようなコロン付き・散文的なタグは禁止。`[Drop]`, `[Break]`, `[Driving Piano, Sleigh Bells]` のように書く。
   - **パイプ `|` 複合記法やボーカル音量指示を混ぜない**: `[Verse 1 | Whispered]` のような複合タグは読み上げ事故や音飛びを招くため、`[Verse 1]` と `[Piano only]` のように単一タグを行分けして記述する。

## 4. Suno 発音・表記ガード

- **漢字仮名交じり＋多音字のみひらがな**: 全編をひらがなに開くと Suno の形態素解析が崩れて棒読みになる。通常の漢字表記をベースに、読みが複数ある語（`今日`→`きょう`、`明日`→`あした`）だけをひらがなにする。
- **読点 `、` とカギ括弧 `「 」` を使わない**: 読点 `、` は入れず半角スペースと改行でブレスを作る。カギ括弧 `「 」` は無音グリッチを招くため外す。
- **数字・英字略語はカタカナに固定**: 発音ガチャや声質ブレを防ぐため、数字（`1, 2, 3`）や略語（`R.I.P.`）はカタカナ表記に固定する。

## 5. Style of Music ＆ パラメータ設定

| 項目 | 推奨設定・ルール |
|---|---|
| **モード** | Custom Mode オン / Instrumental オフ |
| **Style of Music** | 先頭20〜30語に重みが集中するため **「ジャンル → 声質 → BPM/Key → コア楽器（3〜4点） → 全体質感」** の順に絞って配置する（セクション固有楽器や展開指示は歌詞側タグへ分離）。<br>例：`Hyper-cheerful J-Pop, Vocaloid-inspired Idol Pop, Bright Cute Female Vocal, 175 BPM, Bright Major Key, Sparkling Piano, Celesta, Sleigh Bells, Tight Snappy Drums, Dynamic Contrast, Crisp Modern Production` |
| **有害な音響形容詞の回避** | `Fragile`（音圧スカスカ化）や `Lush Voicings`（中低域の濁り）を Style 欄に入れない。静と動の落差をつけたい曲では `Driving` を外し、`Dynamic Contrast` を入れる。 |
| **Exclude Styles** | `sad, dark, melancholy, minor key, slow ballad` 等、2〜3個〜必要最小限に絞る（ネガティブ歌詞の意味逆流を防ぐため、明るい曲では `dark, melancholy` を必ず含める）。 |
| **Style Influence** | `80%`（特にギャップ対比曲では歌詞の暗さに引っ張られないよう強めに固定） |
| **Weirdness** | `25〜35%`（推奨 `30%`。170 BPM 超のアップテンポで 50% にすると拍よれ・音飛びが増える） |

## 6. 制作後チェックリスト（品質・ブレ防止）

- [ ] **トーンと語尾の一貫性**: 軸となる感情トーンにヒステリックな拗ねや、キャラと矛盾する感傷的な語尾（`〜なの` 等）が混ざっていないか？
- [ ] **視点とコア名詞**: Aメロ〜1サビに唐突な「先生視点」がないか？ コア名詞は4〜5個に絞られ、サビ末尾が客観描写で伏線回収されているか？
- [ ] **設定書コピペ・直訳の排除**: 解説語や画像の直訳的な不自然表現（`銀のリング` 等）が残り、具体的なモノ・行動に置き換わっているか？
- [ ] **伏線の因果関係と情景の解像度**: 1番の要素が2番以降に繋がっているか？ 短いフレーズに複数の人物・場面を詰め込みすぎていないか？
- [ ] **音数・ブレス**: BPM に合った音数・ブレスの隙間があるか？
- [ ] **表記・メタタグ・Style**: 読点 `、`・カギ括弧 `「 」`・数字・略語・`|` 複合タグ・有害形容詞（`Fragile`, `Lush Voicings`）が残っていないか？

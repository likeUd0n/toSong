# 物語化・リーディング・心理設計ガイド（toSong ステップ2〜4用）

---

## 1. 観察 ＆ 連想メモ（ステップ 2：【絶縁】）

元テキストの思い込み（重力）を断ち切り、次の `script.md` へ発散の種だけを渡す。**この段階ではまだ時間軸・五感・キャラ設定・コンセプトを確定させない。**

### ① 事実ベースの観察インベントリ（解釈禁止・最低5〜8個）
事前テキストの「答え合わせ」だけをして背景や生活感を読み落とすのを防ぐため、解釈に入る前に**画像に描かれている事実だけを箇条書きで洗い出す**。
- **空間・背景の痕跡**：壁のポスター、植物、椅子の傷み、窓の外の電車や路面（水たまり・点字ブロック等）
- **手元・小道具の状態**：PC画面の明暗、カップの湯気、ノートの開閉、ポケットに入れた手
- **複数枚間の微細な差分**：1枚目と2枚目で変わった口元・目線・肩の力・手の位置

> ここで拾った「偶然のディテール」を、そのまま後の `script.md` や歌詞の小道具・比喩へ接続する。

### ② インスパイア ＆ 連想ジャンプ（プロカメラマンの着眼点）
観察した事実をただ説明・補完するのではなく、**プロのカメラマン／作詞家の目で「なぜこれが写っているのか」を切り取り、記憶やジレンマへ連想を飛ばす**。
- **カメラマンの着眼点（切り取りと違和感）**：なぜこのピンボケ・この影・この余白なのか。画面の隅に写り込んだ生活の綻びや、対比（光と影、熱と冷たさ）から物語の切り口を探す。
- **事象 → 記憶の連想**：目の前の物理的な「事象」（例：机の端の輪ジミ、片方だけのイヤホン）から、主人公の「過去の記憶」や「言えなかった一言」へ連想を1段飛ばす。
- **矛盾とジレンマの抽出**：主人公の中で解決せずに同居している相反する本音（例：「忘れたいのに、通知だけは待っている」「大人になりたいのに、子どもみたいに拗ねている」）を、無理に綺麗な結論へまとめずそのまま核として置く。

## 2. 歌を意識しない「戯曲・MV台本」を書く（ステップ 3：【実験】`script.md`）

散文の小説だと「彼は寂しかった」と心理を説明してしまいがち。**ここでは歌詞になることや事前設定を一度忘れ、3〜4シーン（場所1〜2か所）程度の「短い一幕劇（MV台本）」として自由に動かす。**

### 4トラックの台本フォーマット
各シーンは必ず次の4要素を並べて書く（映像用語の羅列ではなく、「視線・距離・音・動き・言葉」を揃える）：

```markdown
### シーン2：帰り道の高架下
- [映像 / カメラ]：主人公の足元（水たまり）への寄り（インサート）→ 見上げる高架橋の主観ショット（POV）。車のヘッドライトが水面を横切る。
- [音 / 環境]：頭上の電車の轟音 → 遠ざかって無音に近くなる。遠くで信号の電子音。
- [ト書き]：スマホをポケットにしまい、濡れた靴先を1回だけ見下ろす。
- [セリフ / 心の声]：（声に出さず、息だけ）「……まあ、いっか」
```

### 執筆のルール
- **心理を説明しない**：「悲しい」「迷っている」と書かず、目線の逸らし方や手元の動き（`[ト書き]`）、声に出せない本音（`[セリフ / 心の声]`）で表現する。
- **`[セリフ / 心の声]` でテーマを解説しない**：教訓やまとめを主人公に言わせない（悪い例：「矛盾したままだけど、自分で選んだ道にいる」）。口をついて出る短い呟き・言い淀み・身体の違和感（例：「あ、またやってる」「冷たっ」「……まあ、いっか」）にとどめる。
- **カメラは「距離感と視線」を書く**：引きの絵（環境）と、主観ショット（POV）・インサートカット（温度や空気を語る小道具のアップ）を織り交ぜる。
- **`[音 / 環境]` で静と動の緩急を作る**：音の飽和から無音への引き算など、後の `genStyle`（`styles.txt`）や `[Break]` 設計の種になる変化を入れる。
- **「綺麗なまとめ」を急がない**：人間の弱さ・矛盾・小さな後ろめたさを生々しく描いた先に、ふと視界や光が切り替わる瞬間が自然に訪れるようにシーンを置く。

## 3. 設計の確定（ステップ 4：【結晶】`concept.md` / `ペルソナ.md`）

画像（ステップ 1）と戯曲・MV台本（ステップ 3）の実験で立ち上がった世界から、**一番強く残った芯**を抽出し、後半工程がブレないよう言語化・固定する。

### ① コンセプトと観客視点の確定（`concept.md`）
| 項目 | 問いかけ |
|---|---|
| **曲のコンセプト** | 台本の実験を経て、この曲は何を伝える／反転させる曲として結晶したか？ |
| **リスナーの初期状態** | 聴き始める前の観客はどんな気持ちか？ |
| **リスナーにどうなってほしいか（ゴール）** | 聴き終えたあと、観客にどう変化してほしいか？ |
| **捨てる要素（Not-To-Sing）** | 1曲の芯を強くするために、今回あえて歌わない情報 |

### ② 時間軸・周囲の音の流れ・五感の整理
- **時間の進み**：朝 → 昼 → 夕 → 夜 のように、台本内でどの時間帯からどの時間帯へ移動するか（例：昼の雑踏 → 夕方の帰り道 → 深夜の部屋）を確定する。
- **周囲の音の流れ（Soundscape）**：時間の進行に合わせて環境音がどう引き算されるか（例：電車の轟音・雑踏〔飽和〕 → 遠ざかる街の音 → 深夜の無音と遠い風〔極限の引き算〕）を言語化する。
- **視覚・聴覚（ベース）**：光の色温度、影、周囲の環境音とそれに重なる楽器。
- **触覚（◎ 必須）**：寒さ・風・肌触り（冷たい夜風、冷めきった陶器、手のひらの熱）を必ず拾い、「今そこにいる身体性」を残す。
- **嗅覚・味覚（○ 1点スパイス）**：時間や場所の切り替わりを伝えるスイッチ（雨上がりのアスファルトの匂い、渋くなった紅茶等）を1曲に1箇所だけ確定する。

### ③ キャラクター化された濃いペルソナとコア楽器を確定する（`ペルソナ.md`）
環境メモだけで終わらせず、**「1曲の主人公としてリスナーが感情移入でき、声と歌詞のトーンまで決まるキャラクター」** を描く。`Suno作曲メソッド.md` と作詞・作曲のペルソナ設計要素に基づき、以下の項目を埋めること。
- **基本輪郭と生活の癖**：年齢・立場・よくいる場所・ついやってしまう深夜の習慣や小さな見栄。
- **視点・宛先・口調（Perspective & Voice）**：誰の視点で（一人称「僕／私／俺」や三人称）、**誰に向けて歌うか**（自分への独白／特定の「君」／世間）。また、この人物が使いそうな語彙・口調（素朴、皮肉混じり、丁寧など）を決め、1曲を通して視点をブレさせない。
- **関係性と切実さ（Drama & Stakes）**：誰に対してどんな想いを抱えているか（恋愛・葛藤・比較など普遍的な共感軸）と、**「このまま変われないと何を失うのか／本当は何を守りたいのか」** という切実さ（サビで歌う理由）。
- **外に見せる自分 vs 内側の本音（強さと弱さ）**：人前で見せる自分（平気なフリ・強がり・役割）と、1人になったときに顔を出す本当の自分（弱い自分、言えない想い、諦めきれない願い）。
- **画像・台本からの統合**：画像に描かれた細部と台本の `[ト書き]` で表れた癖が、このキャラのどんな性格や心理を物語っているかを紐づける。
- **コア楽器・声と曲調の輪郭（Vocal & Sonic Link）**：空気感に合うコア楽器（3〜4点）と、ペルソナの性格・心理状態に合う**声質・歌い方**（例：囁き、投げやり、少し掠れた地声）、**メロディ・リズムの方向性**（例：狭い音域で語るAメロ → 視界が開けるように跳躍するサビ）を確定する。これがそのままステップ 6（`genStyle`）と歌詞の譜割り設計につながる。

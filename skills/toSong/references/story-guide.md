# 物語化・リーディング・心理設計ガイド（toSong ステップ2〜4用）

---

## 1. 観察 ＆ 連想メモ（ステップ 2：【絶縁】※A / B1 / B2 で実施｜B0 はスキップ）

> [!NOTE]
> **ルート別の扱い**
> - **ルート A（断片・種）**：画像のみを観察 → 抽選 → 未選要素は使用禁止。
> - **ルート B1（要件・ブリーフ）・B2（体験談・日記）**：範囲 X や感情結論を伏せて観察 → **NG 条件のみブラックリスト除外** → 抽選（文脈の必須小道具を守るため未選要素の使用禁止は強制しない）。
> - **ルート B0（資料忠実）**：設定が完結している／発散を足したくない資料は、このステップを完全スキップして **「2. 歌を意識しない戯曲・MV台本」** へ直行する。

元テキストの思い込み（重力）や、LLM がテーマに都合のいい要素ばかりを足し算・ベタ連想してしまう癖を断ち切り、次の `script.md` へ発散の種を渡す。**この段階ではまだ時間軸・五感・キャラ設定・コンセプトを確定させない。**

### ① テーマ非公開の観察（日常語 A/B バケツ列挙）
事前テキストの「答え合わせ」やベタな連想を防ぐため、**元テキスト・範囲 X・核テーマ・感情の結論を一切渡さない別コンテキスト（サブエージェント等）**を使い、写っている／思い浮かぶ要素を**「日常で名前を言えるモノ（分かりやすい日常語）」**に絞って次の 2 つのバケツに列挙する（各 5〜8 個）。
- **ルート A**（および **B1 / B2 でステップ 1 画像を作った場合**）：画像だけを見せる。
- **ルート B1 / B2（画像なしの場合）**：範囲 X や感情語・ジャンル語・商品名・比喩をすべて伏せ、**「時間・場所・物理状態」の 3 点**だけを渡す（例：「真夏の昼過ぎ、日差しが強い街中」「大きな家具を 1 つ運び出したあとの、午後の部屋と玄関」）。
- **バケツ A（馴染みの軸）**：曲の主役・舞台として違和感なく使える馴染みのあるモノ・空間（例：横断歩道、路線バス、自販機、信号機）。
- **バケツ B（日常の細部）**：生活感・質感・偶然性を運ぶ細部（例：濡れたアスファルトの反射、靴先の汚れ、空車ランプ、ほどけた靴紐）。

> ※ サブエージェントが使えない環境では、「いま元テキストと範囲 X を忘れたつもりで、画像（または物理 3 点）だけから日常名詞を A/B に分けて列挙する」と明示的に切り替えて行う。

### ② NG 除外フィルタ（B1 / B2 のみ） ＆ プログラム乱数による強制抽出
1. **NG 除外フィルタ（B1 / B2 のみ）**：抽選の前にメイン側でバケツを確認し、**範囲 X の NG 条件や世界観破綻に明確に抵触する要素だけ**を除外する（ブラックリスト方式）。「テーマに合いそうなものだけ残す（加点選別）」をするとベタに逆戻りするため行わない。
2. **強制抽出**：LLM の好みで要素を選び直さないよう、`scripts/pick_motifs.py` を使って **バケツ A から 1 個・バケツ B から 1 個をプログラムの乱数で強制抽出** する。
```bash
python scripts/pick_motifs.py --a "要素A1" "要素A2" ... --b "要素B1" "要素B2" ...
```
- **ルート A**：選ばれなかった残りの要素は意図的に引き算（使用禁止）し、抽選された `[A, B]` の 2 要素だけで次工程（連想・台本）を組み立てる。
- **ルート B1 / B2**：文脈上の必須要素（小道具や舞台）まで消さないよう、未選要素の使用禁止は強制しない。抽選された `[A, B]` は「視点をズラす新しい切り口・環境音」として台本に差し込む。

### ③ テーマ接続 ＆ 連想ジャンプ（プロカメラマンの着眼点）
ここで初めてステップ 0 の核テーマ・範囲 X と抽選された `[A, B]` を突き合わせ、**プロのカメラマン／作詞家の目で「なぜこの 2 つが結びつくのか」を切り取り、記憶やジレンマへ連想を飛ばす**。
- **B2（体験談・日記）の感情結論の扱い**：ステップ 0 で一時保留した「感情の結論」は、台本の終盤またはステップ 4 で再接続する（そのまま忠実に落とすか、抽選された `[A, B]` の違和感から少しズラした感情表現に着地させるかをここで選ぶ）。
- **カメラマンの着眼点（切り取りと違和感）**：なぜこのピンボケ・この影・この余白なのか。抽選された 2 要素の対比（光と影、動きと停滞）から物語の切り口を探す。
- **事象 → 記憶の連想**：目の前の物理的な「事象」から、主人公の「過去の記憶」や「言えなかった一言」へ連想を 1 段飛ばす。
- **矛盾とジレンマの抽出**：主人公の中で解決せずに同居している相反する本音（例：「忘れたいのに、通知だけは待っている」「渡れるはずなのに、靴先が濡れることを言い訳にしている」）を、無理に綺麗な結論へまとめずそのまま核として置く。

## 2. 歌を意識しない「戯曲・MV台本」を書く（ステップ 3：【実験】`script.md`）

**全ルート（A / B1 / B2 / B0）の合流地点。**散文の小説だと「彼は寂しかった」と心理を説明してしまいがち。**ここでは歌詞になることや事前設定を一度忘れ、3〜4シーン（場所1〜2か所）程度の「短い一幕劇（MV台本）」として自由に動かす。**

### 4トラックの台本フォーマット
各シーンは必ず次の4要素を並べて書く（映像用語の羅列ではなく、「視線・距離・音・動き・言葉」を揃える）：

```markdown
### シーン2：帰り道の高架下
- [映像 / カメラ]：主人公の足元（水たまり）への寄り（インサート）→ 見上げる高架橋の主観ショット（POV）。車のヘッドライトが水面を横切る。
- [音 / 環境]：頭上の電車の轟音 → 遠ざかって無音に近くなる。遠くで信号の電子音。
- [ト書き]：スマホをポケットにしまい、濡れた靴先を1回だけ見下ろす。
- [セリフ / 心の声]：（声に出さず、息だけ）「……まあ、いっか」
```

### 執筆のルール
- **心理を説明しない**：「悲しい」「迷っている」と書かず、目線の逸らし方や手元の動き（`[ト書き]`）、声に出せない本音（`[セリフ / 心の声]`）で表現する。
- **`[セリフ / 心の声]` でテーマを解説しない**：教訓やまとめを主人公に言わせない（悪い例：「矛盾したままだけど、自分で選んだ道にいる」）。口をついて出る短い呟き・言い淀み・身体の違和感（例：「あ、またやってる」「冷たっ」「……まあ、いっか」）にとどめる。
- **カメラは「距離感と視線」を書く**：引きの絵（環境）と、主観ショット（POV）・インサートカット（温度や空気を語る小道具のアップ）を織り交ぜる。
- **`[音 / 環境]` で静と動の緩急を作る**：音の飽和から無音への引き算など、後の `genStyle`（`styles.txt`）や `[Break]` 設計の種になる変化を入れる。
- **「綺麗なまとめ」を急がない**：人間の弱さ・矛盾・小さな後ろめたさを生々しく描いた先に、ふと視界や光が切り替わる瞬間が自然に訪れるようにシーンを置く。

## 3. 設計の確定（ステップ 4：【結晶】`concept.md` / `ペルソナ.md`）

画像（ステップ 1）と戯曲・MV台本（ステップ 3）の実験で立ち上がった世界から、**一番強く残った芯**を抽出し、後半工程がブレないよう言語化・固定する。

### ① コンセプトと観客視点の確定（`concept.md`）
| 項目 | 問いかけ |
|---|---|
| **曲のコンセプト** | 台本の実験を経て、この曲は何を伝える／反転させる曲として結晶したか？ |
| **リスナーの初期状態** | 聴き始める前の観客はどんな気持ちか？ |
| **リスナーにどうなってほしいか（ゴール）** | 聴き終えたあと、観客にどう変化してほしいか？ |
| **捨てる要素（Not-To-Sing）** | 1曲の芯を強くするために、今回あえて歌わない情報 |

### ② 時間軸・周囲の音の流れ・五感の整理
- **時間の進み**：朝 → 昼 → 夕 → 夜 のように、台本内でどの時間帯からどの時間帯へ移動するか（例：昼の雑踏 → 夕方の帰り道 → 深夜の部屋）を確定する。
- **周囲の音の流れ（Soundscape）**：時間の進行に合わせて環境音がどう引き算されるか（例：電車の轟音・雑踏〔飽和〕 → 遠ざかる街の音 → 深夜の無音と遠い風〔極限の引き算〕）を言語化する。
- **視覚・聴覚（ベース）**：光の色温度、影、周囲の環境音とそれに重なる楽器。
- **触覚（◎ 必須）**：寒さ・風・肌触り（冷たい夜風、冷めきった陶器、手のひらの熱）を必ず拾い、「今そこにいる身体性」を残す。
- **嗅覚・味覚（○ 1点スパイス）**：時間や場所の切り替わりを伝えるスイッチ（雨上がりのアスファルトの匂い、渋くなった紅茶等）を1曲に1箇所だけ確定する。

### ③ キャラクター化された濃いペルソナとコア楽器を確定する（`ペルソナ.md`）
環境メモだけで終わらせず、**「1曲の主人公としてリスナーが感情移入でき、声と歌詞のトーンまで決まるキャラクター」** を描く。`Suno作曲メソッド.md` と作詞・作曲のペルソナ設計要素に基づき、以下の項目を埋めること。
- **基本輪郭と生活の癖**：年齢・立場・よくいる場所・ついやってしまう深夜の習慣や小さな見栄。
- **視点・宛先・口調（Perspective & Voice）**：誰の視点で（一人称「僕／私／俺」や三人称）、**誰に向けて歌うか**（自分への独白／特定の「君」／世間）。また、この人物が使いそうな語彙・口調（素朴、皮肉混じり、丁寧など）を決め、1曲を通して視点をブレさせない。
- **関係性と切実さ（Drama & Stakes）**：誰に対してどんな想いを抱えているか（恋愛・葛藤・比較など普遍的な共感軸）と、**「このまま変われないと何を失うのか／本当は何を守りたいのか」** という切実さ（サビで歌う理由）。
- **外に見せる自分 vs 内側の本音（強さと弱さ）**：人前で見せる自分（平気なフリ・強がり・役割）と、1人になったときに顔を出す本当の自分（弱い自分、言えない想い、諦めきれない願い）。
- **画像・台本からの統合**：画像に描かれた細部と台本の `[ト書き]` で表れた癖が、このキャラのどんな性格や心理を物語っているかを紐づける。
- **コア楽器・声と曲調の輪郭（Vocal & Sonic Link）**：空気感に合うコア楽器（3〜4点）と、ペルソナの性格・心理状態に合う**声質・歌い方**（例：囁き、投げやり、少し掠れた地声）、**メロディ・リズムの方向性**（例：狭い音域で語るAメロ → 視界が開けるように跳躍するサビ）を確定する。これがそのままステップ 6（`genStyle`）と歌詞の譜割り設計につながる。

# 物語化・心理設計ガイド（toSong ステップ 2〜4）

## 1. 観察 ＆ 連想メモ（ステップ 2｜B0 はスキップ）

元テキストの思い込みやベタな連想を断ち切るため、ここではまだ時間軸・五感・コンセプトを確定させない。

1. **テーマ非公開の観察（A/B バケツ列挙）**
   - 元テキスト・核テーマ・感情の結論を渡さない別コンテキスト（サブエージェント等）で、日常語の名詞を各 5〜8 個列挙する。
   - 渡す情報：画像がある場合は画像のみ。画像がない場合は「時間・場所・物理状態」の 3 点のみ。
   - **バケツ A（馴染みの軸）**：主役・舞台になるモノや空間。
   - **バケツ B（日常の細部）**：生活感や偶然性を運ぶ細部。
   - サブエージェントには具体例を渡さない（軽量モデルは例の語をそのまま写し、画像と無関係な定番語が混ざるため）。
2. **NG 除外 ＆ 乱数抽出**
   - B1 / B2 のみ、NG 条件・世界観破綻に反する要素をブラックリスト除外する（加点選別はしない）。
   - `scripts/pick_motifs.py` で **A から 1 個・B から 1 個** を強制抽出する。
   - ルート A では未選要素を使用禁止にする（B1 / B2 では文脈上の必須小道具を残してよい）。
3. **テーマ接続 ＆ 連想ジャンプ**
   - 核テーマと抽選された `[A, B]` を突き合わせ、「なぜこの 2 つが結びつくのか」から記憶への連想と解決しない矛盾・ジレンマを切り取る（B2 で保留した感情結論はステップ 3 終盤〜ステップ 4 で再接続する）。

---

## 2. 戯曲・MV台本（ステップ 3：`script.md`）

**全ルートの合流地点。**歌詞の都合や文字数を忘れ、**3〜4 シーン（場所 1〜2 か所）** の短い一幕劇として自由に動かす。

### フォーマット
```markdown
### シーン2：帰り道の高架下
- [映像 / カメラ]：足元（水たまり）へのインサート → 見上げる高架橋の POV
- [音 / 環境]：電車の轟音 → 遠ざかって無音に近くなる
- [ト書き]：スマホをしまい、濡れた靴先を1回だけ見下ろす
- [セリフ / 心の声]：（息だけ）「……まあ、いっか」
```

### ルール
- **心理を地の文で説明しない**：目線・手元の動き（`[ト書き]`）と短い呟き（`[セリフ]`）で示す。
- **セリフでテーマを解説しない**：教訓や綺麗なまとめを言わせず、人間の弱さや矛盾をそのまま置く。
- **`[音 / 環境]` に緩急をつける**：飽和から無音への引き算など、後の編曲の種を入れる。

## 3. 設計の確定（ステップ 4：`concept.md` / `ペルソナ.md`）

実験（画像と台本）で一番強く残った芯を言語化・固定する。

1. **コンセプトと観客視点（`concept.md`）**
   - 曲のコンセプト、リスナーの初期状態、聴き終えたあとの変化、捨てる要素（Not-To-Sing）を定める。
2. **時間軸・周囲の音・五感**
   - 時間経過（例：朝→夕→深夜）と環境音の変化を確定する。
   - 五感：**触覚は必須**（温度・風・肌触り）、嗅覚・味覚は 1 点スパイスとして入れる。
3. **ペルソナとコア楽器（`ペルソナ.md`）**
   - 基本輪郭・生活の癖、視点と宛先（誰が誰へ歌うか）、外に見せる強がりと内側の本音を定義する。
   - 空気感に合うコア楽器（3〜4点）と声質・リズムの方向性を確定する。

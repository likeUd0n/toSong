# 作詞・音への変換ガイド（toSong ステップ5・7用）

戯曲・MV台本（`script.md`）とビジュアルアンカー（`visual_*.png`）からコア語を抽出し、詩的圧縮を経て Suno AI で実際に歌える歌詞・メタタグへ変換するための手順。

---

## 1. テキストマイニングと詩的圧縮（Script → Poetry）

台本の要約文をそのまま五七調や短文にするのではなく、**ステップ1で生成した画像を見ながら**「抽出 → 引き算 → 圧縮」の3段階で台本を詩に変換する。

### ① ワード・マイニング（全体調和の土台 ＋ スパイス）
元テキスト・中間ブリッジ（`ペルソナ.md`）・`script.md` から、世界を構成する語を次の枠に整理する。
- **モノのコア名詞（3〜4個に厳選）**：曲全体で使い回し、「全体調和」を作る主役の道具（例：画面、ノート、カップ）。展示会にしない。
- **環境の時計（2〜3個）**：時の進み（朝→昼→夜）、季節・天候（雨上がりの交差点、黄色いイチョウ、夜風）、周囲の音の流れ（電車の音→遠い風）を運ぶ語。
- **スパイス・キーワード（1〜2個・フック）**：全体調和だけに寄せると優等生的・予定調和になりやすいため、聴き手の耳に引っかかる**「異質な固有語・生々しい生活語・逆説のキラーフレーズ」**を1〜2個だけ意図的に混ぜる（例：半額シールの跡、言い訳のストック、未送信の下書き）。
- **行動の理由（心理のフック・1文でピン留め）**：「なぜ主人公は立ち止まるのか／動くのか」という**動機・因果**を1文で固定しておく（例：靴が濡れることばかり気にして踏み出せない自分が嫌になる）。ステップ 7 で文字数を削るときも、この接続だけは削り落とさず前半〜サビのどこかに残す。

### ② 感情フィルター（比喩の反転 ＆ ジレンマの同居）
同じ物理モチーフ・五感であっても、**主人公の心の状態によって知覚と比喩を反転**させる。さらに、綺麗な「不安→回復」の反転だけでなく、**矛盾やジレンマを解決しないまま並べる**視点も持つ（例：手放したいはずのモノを、一番取り出しやすいポケットに入れている）。歌詞を書く前に「不安／停滞時（1番）」と「回復・納得・あるいは矛盾の抱え込み（サビ）」の見え方を表で定義する。
- 例：**雨上がりの交差点（水たまり）**
  - 不安時（1番）：揺れる水面にビルと自分が歪んで映り、「ちゃんと歩けているだろうか」と不安になる鏡。
  - 回復時（サビ）：水たまりさえ街灯を跳ね返して、自分の足元を照らしてくれる味方。

### ③ 自由詩の執筆（制約を外してインスパイアのまま書く）
`script.md` の要約・補完に陥らないよう、**ステップ 2 の連想ジャンプ（事象→記憶・ジレンマ）とスパイス・キーワードを起点に**、行数・拍数・禁止事項などの制約をいったんすべて外して純粋な「詩」として好きに書く。
- **なぜ自由に書くか**：生成の段階で細かいルールを課すと表現が縮こまり、優等生的な文章になるため。ここでは詩としての飛躍・リズム・美しい余白を思い切り伸ばし、次の工程（歌詞化）で歌の器に合う部分を選び取って整える。

### ④ 日本語としての自然さガード
> [!IMPORTANT]
> - **画像キャプションの直訳語を使わない**：Visual Reading で見たままを直訳した不自然な語（例：`銀のリング` → `銀の指輪` / `指輪`、`オレンジのライトの輪の中` → `オレンジの明かりの下` / `デスクライトの丸い光`）は、日常や歌詞で自然な日本語に言い換える。
> - **音数圧縮で主語（モノ）を落とさない**：`script.md` を短くするときに「画面」「時計」「予定」などのモノを削り、時刻や色そのものを主語にしない（悪い例：`0時15分がそっと光る` / `0時15分の小さな色` → 良い例：`画面の隅 0時15分が灯る` / `スマホに灯った深夜の印` のように何が光るかを残す）。
> - **「〜の〜の〜」の連鎖を避ける**：名詞を「の」で3つ以上つながず、動詞（「照らす」「浮かぶ」「にじむ」）で情景を動かす。

## 2. 言葉を「音」にするための設計プロトコル

LLM は音声を聴けないため、言葉を並べる前に**数値・モーラ・母音の設計図**を作る。また、Suno は歌詞欄を**音素（Phonetic）とタイムライン**として解釈し、**改行・句読点（、）・スペースを「ブレスと休符の位置」**として処理する。

> [!IMPORTANT]
> **歌詞化における優先順位（音を揃えるために意味を壊さない）**
> 1. **意味・因果が通ること**（なぜ主人公がそうしているかの動機が追える）
> 2. **自然な日本語であること**（主語・述語が揃い、音読して違和感がない）
> 3. **音数（モーラ）・母音の設計**
> - モーラ数や母音合わせのために、述語を消して文を途中で切ったり（例：`〜テールランプが` で終わる）、不自然な省略・古語化（例：`濡れぬようとめた`）をしない。
> - モーラ数は固定値（全部14音）で揃えず、表のレンジ（10〜15音など）の幅を使って自然な語順を優先する。

### ⓪ ラスサビ先作り（核のフックから逆算する）
いきなり Aメロの1行目から順番に書かず、**まず曲の心臓部である「ラスサビ（または1サビ）の決めフレーズ」を最初に作る**。
- ラスサビで鳴らしたい**母音ライム・開口母音・スパイスキーワード・リズムの跳躍**を先に確定させ、そこから逆算して Aメロ・Bメロ（助走と伏線）と Cメロ（切り返し）を設計する。
- ※ Suno 実機でメロディ・声質の当たりを先に引きたい場合は、このラスサビ単体＋`style.txt` で一度生成し、当たりクリップを **Cover / Persona** にしてフル歌詞を展開する運用もできる。

### ① モーラの正確なカウントルール（文字数と混同しない）
LLM は「文字数」と「モーラ（拍）数」を混同しやすいため、以下を厳密に区別する。
- **1モーラとして数えるもの**：通常の仮名1文字、促音「っ」、撥音「ん」、長音「ー」（例：`きょうと` = `きょ(1)・う(1)・と(1)` で **3モーラ**）
- **前の文字と合体して1モーラになるもの**：拗音の小書き文字「ゃ・ゅ・ょ」（例：`しゃ` = 1モーラ、`きゅう` = 2モーラ）

### ② 音数（モーラ）グリッドと「2行刻み・空白ズラし」
曲の BPM に応じて1行の音数レンジを先に決め、セクション内で揃える。**1行が長すぎると Suno が早口で詰め込む**ため、1フレーズ（5〜10文字、または半小節〜1小節）ごとにこまめに改行・スペースを入れてブレスの隙間を作る。
- **Aメロの2行刻みレイヤリング**：4行を1ブロックにせず、2行ごとに `[Piano only]` → `[Add Soft Kick]` → `[Add Soft Bass]` のように少しずつビートを足す。
- **空白によるリズムのズラし**：全行を文節通り綺麗にスペース区切りすると単調になるため、あえて拍を跨ぐ位置に半角スペースを入れて（例：`ぬるく なった半分 の水`）溜めやグルーヴを作る。

| BPM帯 | Aメロ（Verse）目安 | Bメロ（Pre-Chorus）目安 | サビ（Chorus）目安 |
|---|---|---|---|
| **アップテンポ（160〜185 BPM）** | 15〜17 音前後（2行に分けても可、ブレス確保） | 前半 12〜14 音 → 後半は短く刻む | 12〜16 音のキャッチーな反復 |
| **ミドル（110〜145 BPM）** | 12〜15 音（余白を残す） | 10〜14 音 | 10〜15 音 |
| **バラード（70〜100 BPM）** | 8〜12 音（1音節を長く伸ばせる量） | 8〜12 音 | 8〜12 音（母音で伸ばす余白） |

### ③ 母音（ライム）と歌唱しやすい音韻設計（人間目線）
- **強拍・行末の母音ライム（聴き心地の快感）**：Aメロのペア行やサビの決めフレーズは、行末や拍の頭（2拍目・4拍目）の母音を揃えて聴覚的な快感を作る（例：`a→a`, `i→i`, `o→o`）。
- **高音・ロングトーンの開口母音（歌いやすさ）**：サビの頂点や語尾を伸ばす位置には、口が開いて響きやすい **開口母音（`a, e, o`）** を優先配置する。`i, u`（特に無声子音 `k, s, t, p, h` に挟まれた `i, u`）は喉が締まりやすく音も抜けにくいため、高音の決め所では避ける。
- **調音のもつれ回避**：両唇音（p/b/m）・歯茎音（t/d/s/n/r）・軟口蓋音（k/g）の急激な連続や、促音「っ」・拗音の密集を避け、**生身の人間が気持ちよく口を動かしてブレスできる語順**にする。
- **高低アクセントの自然さ**：日本語は高低アクセントの言語のため、一度ひらがなに開いて朗読したときに不自然に意味が取りづらい語順を避ける。

### ④ 2段階監査：意味・文脈監査 → モーラ・譜割り監査（生成とチェックの分離）
作詞（詩的表現）と数値チェックを同時にやると字余りや意味の欠落が起きやすいため、歌詞を書いた後に**必ず次の2段階の順で監査**する。

1. **第1関門：意味・文脈監査（数値を見る前に必ず行う）**
   - 台本（`script.md`）や自由詩（`poetry.md`）を知らない第三者の目線で歌詞全体を通読し、**「主人公が何をしていて、なぜそうしているか」**が追えるか確認する。
   - 1つのブロック内で主語が接続なしにすり替わっていないか、述語が抜けて途中で切れている行がないかを確認する。
   - 前半（実景）と後半（内面・比喩）を繋ぐ「行動の理由（心理のフック）」が前半〜サビに置かれているか確認する。
2. **第2関門：モーラ・譜割り監査（第1関門を通った後で行う）**
   - **ひらがな＋小節線 `/` に展開**してモーラ数・拗音・促音とブレス位置（改行・スペース）を監査する（例：`き・み・の / か・ぜ・の / お・と — / —`）。

### ⑤ 「にごり」とセクション別の役割（静と動・味変・回収）
- **A・Bメロ**：硬い書き言葉を避け、口語・言い淀み（`あ、いや`）・崩し（`〜とか` `〜んでしょ`）などの「にごり」で人間味を出す。
- **BメロのV字コントラスト（引き算と止まり）**：停滞・苦しさを描く曲では `[Build-up]` を使わず、`[Half-time]` `[Sparse Piano]` で一度音を落とし、サビ直前に `[Break]`（一拍の無音）を置いてからサビで一気に解放する。
- **サビ末尾の着地（客観→主観→客観描写）**：サビの最後を「少しずつ動き出すよ」のような抽象的感想で終えず、Aメロで出したコア名詞を「アクション後に見え方が変わった映像」として再登場させ、伏線回収する。
- **Cメロ（Bridge）の語り手味変**：Aメロ〜1サビのトーンを揃えた上で、Cメロだけは「他者の声（外圧）の引用」や「もう一人の自分への強い呼びかけ・命令形」へスイッチし、ラスサビへの推進力を生む。
- **スパイス・キーワードの配置（引っかかりの設計）**：ステップ 5 で用意したスパイス・キーワード（1〜2個）を、Aメロの1行目（掴み）・サビの決め・Cメロの切り返しなど最も耳に残る位置へ配置し、予定調和を崩す。

## 3. Suno AI 向けメタタグ・発音ガード（必須チェック）

`references/Suno作曲メソッド.md` に基づく技術的制約：

1. **メタタグは「1〜2語・英語名詞ベース」で行分けする（パイプ `|` 禁止）**
   - 良い例：`[Intro]` / `[Driving Piano]` / `[Break]` / `[Pre-Chorus]` / `[Build-up]` / `[Chorus]` / `[Full Band]`
   - 悪い例：`[Verse 1 | Soft Piano, Whispered Breath]` や `[Sudden warm burst: ...]`（`|` や `:` を含む複合・長文タグ、また `Whispered` 等のボーカル音量指示は読み上げ事故や音飛びの原因になる）。
2. **セクション間のビルドアップ分離と1サビの解放**
   - Bメロと Cメロ（Bridge）で同じ盛り上げ方を重ねない（停滞・葛藤を描く曲では Bメロを `[Half-time]` `[Sparse Piano]`＋`[Break]` の引き算にし、Cメロで `[Building Drums]` を使う）。
   - 1サビに `[Light Rhythm]` のような弱めるタグを置くと Bメロに負けるため、1サビも `[Full Band]` `[Explosive Chorus]` でしっかり鳴らし、大サビとの差は `[Lush Strings]` `[Grand Finale]` や転調でつける。
3. **発音ガチャ・無音グリッチ防止（漢字仮名ハイブリッド）**
   - **全ひらがな禁止**：すべてをひらがなにすると形態素解析が壊れて棒読みになる。通常の漢字仮名交じりをベースに、**読みが複数ある語（`今日`→`きょう`、`明日`→`あした`、`私`→`わたし`）だけ**をひらがなにする。
   - **読点 `、` とカギ括弧 `「 」` を使わない**：無音グリッチや変な間を防ぐため、ブレスは **スペースと改行** で作る。
   - 英字略語（`R.I.P.`, `SNS`）はカタカナ表記に固定し、英語フレーズは1行丸ごとにせず短い合いの手にとどめる。

## 4. 作詞後のセルフチェックリスト
- [ ] **意味・因果の貫通（第1関門）**：台本を知らない人が読んでも「何をしていて、なぜそうしているか」が追え、主語・述語の欠落や無理な省略がないか？
- [ ] **時の進みと環境**：朝→昼→夜などの時間経過、季節・天候、周囲の音の流れ（飽和→引き算）が感じられるか？
- [ ] **五感と比喩**：視覚・聴覚だけでなく、触覚（温度・風）や1点の嗅覚/味覚が入り、同じ景色が心の変化で別の比喩に反転しているか？
- [ ] **インスパイアとスパイス**：台本の説明・補完にとどまらず、連想やジレンマが表現され、耳に残る「スパイス・キーワード（1〜2個）」が効いているか？
- [ ] **タイトル一貫性**：最後のタイトルが、ラスト1行だけでなく 1番・2番・サビのすべてと繋がっているか？
- [ ] 画像（`visual_*.jpg`）の具体的な情景や生活の痕跡が歌詞に入っているか？
- [ ] 「私だけは理解できる」と思わせる具体的な弱さ・矛盾が入っているか？
- [ ] 設定資料の解説語をそのままコピペしていないか？
- [ ] 画像の直訳語（例：`銀のリング`）、「〜の〜の〜」の連鎖、主語を省いてねじれた描写（例：`0時15分が光る`）がなく、音読して自然な日本語になっているか？
- [ ] 1行の音数が揃い、数字・略語のカタカナ化と `「 」`・読点 `、` の除去ができているか？
- [ ] **歌唱感・聴感**：ラスサビの頂点やロングトーンに開口母音（`a, e, o`）が乗り、早口のもつれがなく、強拍・行末の母音ライムが気持ちよく響くか？

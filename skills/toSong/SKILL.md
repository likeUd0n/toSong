# テキスト・ファイルからの楽曲生成（toSong）

いきなり歌詞や設計書を書かず、**「コンセプト（文字）→ 絵（偶然性・生活感）→ 感じる（リーディング）→ 戯曲・MV台本（映像・音・セリフ）→ 詩（マイニング・圧縮）→ 音（Style・歌詞）→ タイトル（最後）」** の順で構築する。

## 必須の設計原則
1. **モチーフ設計は「画像を見た後」に行う**：テキストで先に細部を固めると絵が答え合わせになる。画像に偶然描かれた生活感・光・矛盾を**感じて**から、モチーフとペルソナを立ち上げる。
2. **歌詞の前に「戯曲・MV台本（マルチメディア・テキスト）」を書く**：心理を言葉で説明せず、「カメラ（視線・距離）」「音（環境音・沈黙）」「ト書き（動き）」「セリフ」の4層でシーンを組むことで、映像が浮かぶ歌詞と曲展開の設計図を同時に作る。
3. **タイトルは最後に決める**：制作中は仮名で進め、絵・台本・歌詞が揃った最後の余韻から命名する（説明的なタイトルを避ける）。
4. **観客視点と心理モデル**：`Suno作曲メソッド.md` と心理学的観点（弱さ・矛盾・「私だけは理解できる」共感・先生視点の教訓）を組み込む。

## 制作パイプライン（全8ステップ）

> [!TIP]
> **確認ゲートの運用**
> 一気通貫の指定がない限り、**ステップ 1（コンセプト）** または **ステップ 3〜4（画像のリーディング・短編物語）** で一度ユーザーとイメージをすり合わせると手戻りを防げる。

### ステップ 0：入力の棚卸し・削ぎ落とし（仮フォルダで開始）
- 元テキストから核となるテーマ・感情軸を1つだけ選び、1曲に収まらない要素（Not-To-Sing）を切り離す。
- 曲調の軸（ストレート寄り添い vs ギャップ対比）と大まかな BPM 帯を決める。
- 作業中は仮のフォルダ名（例：`~\Music\Suno\_draft_<日付>\`）で進める。

### ステップ 1：コンセプト ＆ 観客視点の言語化（書き言葉のみ）
詳細は [story-guide.md](references/story-guide.md) を参照。
- **曲のコンセプト**と**観客視点（聴き終えたリスナーにどうなってほしいか）**を書き言葉で定義する。
- ※ この段階ではまだ「モチーフ（楽器・小道具）」や「ペルソナの細かい性格」を固めない。

### ステップ 2：ビジュアルの変数的生成（画像担当：1〜2枚）
`image-generator` サブエージェントでキービジュアルを **1〜2枚（空間・時間帯の対比）** 生成する。
- **画像に任せる領域**：季節感、光の色、偶然の生活の痕跡（小物や服装の矛盾）。プロンプトには舞台と大枠のトーンだけを指定し、細部はあえて余白（変数）を残す。
- **テキスト側へ逃がす領域**：間の時間経過（夕方など）、目に見えない五感、MV的なカメラワーク（主観POV・寄り引き）や音の変化は無理に何枚も生成せず、次のステップ 3〜4 でテキスト補完する。

### ステップ 3：【感じる・読み解く】Visual & Sensory Bridge（★コア工程・`ペルソナ.md`）
詳細は [story-guide.md](references/story-guide.md) を参照。画像（点）から、台本（線）の土台となる世界観・五感・キャラクターを確定する。
1. **時間軸・季節・周囲の音の流れ**：1日の進行（朝→昼→夜等）、季節・天候、そして周囲の環境音がどう変化するか（例：電車の轟音・雑踏 → 遠ざかる街音 → 深夜の無音・夜風）を言語化する。
2. **五感の言語化**：視覚・聴覚に加え、**触覚（冷気・風・肌触り）は必須**で拾い、嗅覚・味覚は場面転換の1点スパイスとして加える。
3. **モチーフ・コア楽器・キャラクター化されたペルソナ確定**：感じた空気感からコア楽器（3〜4点）を決め、さらに「好きなのに告白できない弱い自分」「平気なフリをする強い自分」のように、**外に見せる自分（強がり・役割）と内側の本音（弱さ・願い）を抱えた、共感できるキャラクター**を詳細に立ち上げる。

### ステップ 4：戯曲・MV台本の執筆（`script.md`）
詳細は [story-guide.md](references/story-guide.md) を参照。
- **歌や歌詞の都合を一度すべて忘れる**（1番・2番・サビの構成や文字数制限を意識しない）。
- 3〜4シーン程度の短い一幕劇として、各シーンを **`[映像 / カメラ]` `[音 / 環境]` `[ト書き]` `[セリフ / 心の声]`** の4トラックで書く。
- 心理を地の文で説明せず、カメラの距離・視線（POV・インサート）、環境音の切り替わり、身体の動きと言葉のギャップで表現する。

### ステップ 5：ワード・マイニング ＆ 詩的圧縮（台本 → 詩の骨格）
詳細は [lyrics-guide.md](references/lyrics-guide.md) の「1. テキストマイニングと詩的圧縮」を参照。いきなり歌詞の文字数合わせに入らず、まず台本を「詩」に変換する。
1. **ワード・マイニング（モノ＋環境の時計）**：元テキスト・中間ブリッジ・`script.md` から語を抜き出し、**「モノのコア名詞（3〜4個）」** と **「時間・季節・周囲の音を運ぶ環境の時計（2〜3個）」** だけを残す。
2. **感情フィルター（知覚の比喩変換）**：同じ物理モチーフ・五感が「不安／停滞時（1番）」と「回復／納得時（サビ）」でどう別の比喩に反転するかをマトリクスで定義する（例：揺れる水たまり＝不安な鏡 → 足元を照らす味方）。
3. **自由詩の執筆（`poetry.md`：制約を外して好きに書く）**：文字数・行数・禁止ルールなどの制約をいったん忘れ、`script.md` の映像・音・セリフから立ち上がったイメージを**純粋な「詩」として好きに書き切る**。その豊かな表現の中から、ステップ 7 で歌に合うフレーズを選び取る。

### ステップ 6：Style of Music の生成（`genStyle` スキル）
`../genStyle/SKILL.md` を読み、ステップ 3 で感じた音・空気感とコア楽器、およびステップ 4（`script.md`）の `[音 / 環境]` の緩急をもとに `styles.txt` を作成する。

### ステップ 7：詩の骨格から歌詞への翻訳（`<曲名>.txt`）
詳細は [lyrics-guide.md](references/lyrics-guide.md) を参照。
1. **詩的骨格のセクション展開**：ステップ 5 で作った「詩的骨格」とコア語を、1番→2番→Cメロ→ラスサビへ配置する（新しい名詞を増やさず、同じ語の視点・見え方を変えて回収する）。
2. **音数グリッド・母音設計**：BPM に合わせたモーラ数とライムを設計。
3. **モーラ・譜割り監査（生成とチェックの分離）**：ひらがな＋小節線 `/` に展開し、拗音・促音とブレス位置（改行・スペース）を監査する。
4. **Suno メタタグ・発音ガード**：`[Tag]`（1〜2語・行分け）、難読漢字のひらがな開き、数字・略語のカタカナ固定、カギ括弧 `「 」` と読点 `、` の除去。

### ステップ 8：タイトルの命名 ＆ 一貫性チェック・整理
- **最後にタイトルを決める**：完成した画像・物語・詩・歌詞の全体を見渡し、説明的にならない**象徴的・余韻の残るタイトル**を命名する。
- **タイトル一貫性（バックリンク）チェック**：決めたタイトルが示す核のイメージや時間軸が、ラスト1行だけでなく **1番・2番・サビのすべてで伏線として鳴っているか** を確認し、必要なら1番の描写に微調整を入れる。
- **貼り付け用データと制作データの分離**：
  - プロジェクトルート（`~\Music\Suno\<曲名>\`）には **Suno へそのままコピペできる貼り付け用ファイルだけ** を置く（`title.txt`, `lyrics.txt`, `style.txt`, `exclude.txt`, `settings.txt`）。
  - 制作過程のデータ（`script.md`, `ペルソナ.md`, `poetry.md`, `visual_*.png/jpg`, `review.md`, 過去バージョン等）は **`work\` サブフォルダ** にまとめる。
- ユーザーに一式を報告し、仕上げのブラッシュアップとして **`/song-review`** を提案する。

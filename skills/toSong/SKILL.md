# テキスト・ファイルからの楽曲生成（toSong v3）

中間工程の画像生成を外し、**③構成作家（主人公の人物像＋因果の通った4コマプロット）**と**④生活実感メモ（誰でも覚えのある小さな仕草・身体感覚）**から、聞いて1秒で映像が浮かぶ歌詞を立ち上げる。作詞家を元の種から隔離し、VOICEVOX 音声チェッカーで音韻・多音字・反復を自動検証する。

---

## 事前確認：利用プラン・作業場所

- **作業場所**：曲の中間ファイル・最終出力・設定ファイルは、現在の作業フォルダ配下の `songs/` にまとめる。
- **利用プラン**：`songs/preferences.json`（例：`{"plan": "free"}`）を確認し、すでに `"plan"`（`"free"` / `"paid"`）があればそのまま使う（変更指定時のみ更新）。未設定時のみ「無料版（Free）か有料版（Pro / Premier）か」を聞き、同ファイルに保存する。

---

## 全体の流れ（6ロールリレー）

```
[種] ─▶ ①配達員 ─▶ ②選別者 ─▶ ③構成作家 ──────────▶ ④生活実感メモ
        (事実)      (核1-2個)   (人物像＋起承転結4コマ)  (仕草・身体感覚・3スイッチ)
                                      │                        │
                             (人物像＋出来事・因果)       (生活実感＋3スイッチ)
                                      └──────────┐  ┌──────────┘
                                            【隔離壁】
                                                 ▼
[完成] ◀─ ⑦タイトル・カバー・整理 ◀─ ⑥編曲家（z×歌詞） ◀─ ⑤作詞家 ⇄ [VOICEVOX 音声チェック]
```

> [!IMPORTANT]
> **コンテキスト分離のルール**
> **⑤ 作詞家**に渡すのは、**③ 構成作家の「主人公の人物像」と「4コマプロット（出来事と因果の事実のみ）」**・**④ 生活実感メモ（3スイッチのラベル含む）**の2点だけ。①②（元の種・分析）、③の `y/z` 設計意図は見せない。

作業中は仮フォルダ（`songs/_work/<仮名>/work/`）に各ロールの出力を保存し、最後に曲フォルダ `songs/<曲名>/` へ整理する。

- **所要時間の記録（`work/timing.log`）**：各ロールの開始時に `work/timing.log` へ `HH:MM:SS ロールN` を1行追記し、完了時に `HH:MM:SS 完了` を書く。完了報告に合計時間と最も長かったロールを1行で添える（集計には [calc_timing.py](scripts/calc_timing.py) を使用可）。

## 各ロールの責務（①〜⑥）

### ① 配達員 → `work/01_delivery.md`
- 種（テキスト・メモ・資料）から**事実・出来事・物理状態・時間経過**だけを箇条書きで抜き出す。
- 解釈・感情の補足・タイトル付けは禁止。

### ② 選別者 → `work/02_selection.md`
- ①の事実リストから、**対立する行動・感情の結びつき・中心性**を整理し、**核となるモチーフを 1〜2 個**に絞る。
- 残りの小道具は背景へ退かせ、後工程での名詞の渋滞を防ぐ。

### ③ 構成作家 → `work/03_story.md`
主人公の輪郭を具体化したうえで、**「状態の変化（Before → After）」**と**「因果（だが／だから）」**が通る **4コマプロット（起・承・転・結）** を書く。単なる場面移動（「そして〜」）や2コマ同場面の引き伸ばしは禁止。
- **主人公の人物像（ペルソナ）**：
  - **立場**：年齢感・仕事や学校・暮らしぶり。
  - **性格と癖**：日常で無意識に出てしまう言動や思考の癖。
  - **口ぐせ・心のつぶやき（1行）**：とっさに出る言葉や心の中で繰り返しがちなフレーズ（サビやアウトロの体温の元になる）。
  - **今日あったこと**：曲の直前に起きた具体的な出来事・負荷。
- **変化の軸（1行）**：最初の状態（Before）→ 終わりの状態（After）。
- **4コマプロット（⑤へ渡す事実・因果）**：各コマに `[時間・天候・場所]`・`出来事（外で起きること）`・`前コマとの因果（だが／だから）` を書く。朝→夕方・雨→晴れなどの大きな時系列変化もここで設計する。
  - **起（設定・前提）**：主人公の現在地と抱えている負荷・状況。
  - **承（展開・対比）**：状況が深まる、または対比・引っかかりにぶつかる。
  - **転（転換・反転）**：「だが／しかし」で感情・状況・天候が切り替わる瞬間。
  - **結（着地・余韻）**：変化したあとの新しい状態と行動（起とは少し違う状態で終える）。
- **`y`（歌詞）と `z`（音源）の変動範囲**（別節に分け、⑤には渡さない）：歌詞で描く心の揺れ／音源に預ける空気感・温度レンジ。

### ④ 生活実感メモ → `work/04_life_details.md`
抽象的な心理説明（`寂しそう` `疲れた心` 等）や、特定の絵を見ないと通じない座標実況・偶発的な色描写は禁止。③の人物像と4コマプロットから、**「聞いて1秒で映像が浮かぶ、誰でも覚えのある具体」**だけを抽出する。
- **主人公の人となりが滲む小さな仕草・身体感覚**：4コマそれぞれの場面で、音・温度・重み・手触り・反射的な癖（例：かかとを踏んで靴を脱ぐ、無意識に高い声で愛想よくする等）を具体化する。
- **語彙の鮮度・言い換え案**：核モチーフの直球連呼を防ぐため、感覚翻訳・自然な言い換え案を添える。
- **3つのスイッチ（ラベルのみ）**を指定する：
  1. **構造型**：`演劇型` / `場面切替＋リフレイン型` / `独白型`
  2. **視点・距離**：`至近距離（一人称・身体感覚）` / `並走（二人称）` / `引き（三人称・観察）`
  3. **時間構造**：`物語型（時系列の変化）` / `情景・静止型（1瞬の深化）`

### ⑤ 作詞家【隔離】 → `work/05_lyrics.txt`（および `work/lyrics.txt`）
渡すのは **③の人物像・4コマプロット（出来事・因果のみ）**・**④の生活実感メモ（3スイッチ含む）** のみ。詳細は必要に応じて [Suno作曲メソッド.md](references/Suno作曲メソッド.md) も参照する。

- **優先順位**：**①意味・因果 ＞ ②自然な日本語 ＞ ③音数・母音**（音数のために主語・述語や行動の理由を削らない）。
- **語彙の鮮度**：同じアンカー名詞を直球で連呼せず、④の感覚翻訳・言い換えを使う。座標実況語（`右手の〜` `ドアの上`）や硬い説明名詞（`外廊下` 等）は避け、歌いやすい口語・身体語を選ぶ。
- **ラスサビ先作り**：4コマの着地点を掴んだあと、まず心臓部であるラスサビの決めフレーズ（母音ライム・開口母音）を仮置きし、1番→2番→Cメロを逆算で組む（淡々とした「情景・静止型」は1枚目から順書きでも可）。
- **モーラ・音数グリッド設計**：
  - 1モーラ＝仮名1文字・っ・ん・ー（拗音は前と合体して1モーラ）。
  - 1ブロック（連）は**原則2行（最大でも4行まで）**とし、空行で細かく区切る。
  - 1行を詰め込まず半小節〜1小節ごとに改行・スペースでブレスを作る。
  - 目安：**160〜185 BPM**（A:15〜17 / B:12〜14→短 / サビ:12〜16）、**110〜145 BPM**（A:12〜15 / B:10〜14 / サビ:10〜15）、**70〜100 BPM**（各8〜12音）。
- **メタタグと緩急（楽器の細かな抜き差し）**：
  - 1〜3語の標準英語名詞を `[Tag]` 単独行で書く（`|` 複合、`:` 説明、`[Break]` 直下の歌詞、1サビ `[Light Rhythm]` は避ける）。
  - **2行ブロックごとに楽器を細かく増減させる**：Verse 1 の前半は `[Acoustic Guitar Only]` や `[Sparse Piano]` など最小編成で始め、後半2行で `[Add Soft Percussion]` `[Add Bass]` のように1つずつ足して推進力を作る。
  - **サビ前の落とす→解放**：Pre-Chorus は `[Half-time]` や `[Build Up]` ＋ `[Break]`（直後に `[Chorus]`）で落差を作り、サビを `[Full Band]` で解放する。
  - **2番・Bridge・Outro の引き算**：Verse 2 は `[Bass and Drums]` → `[Add Clean Electric Guitar]` 等で1番と質感を変え、Bridge は `[Stripped Back]` で一度引き算してからラスサビへ繋ぐ。BメロとCメロで同じ盛り上げ方を重ねない。イントロのモチーフをアウトロでも響かせる。
- **表記ルール**：漢字仮名交じり基本、多音字や誤読されやすい漢字（`きょう` `あした` `よかぜ` `かど` `もちて` 等）はひらがなにする。読点 `、` とカギ括弧 `「 」` は使わずスペースと改行でブレス。数字・英字略語はカタカナ固定。
- **2段階監査（音声・音韻チェック自動組み込み）**：
  1. **第1関門（意味・文脈）**：台本を知らない読者目線で「主人公が何をしていてなぜそうしているか」「主語・述語が揃っているか」「聞いて1秒で映像が浮かぶか」を確認。
  2. **第2関門（音韻・表記チェッカー）**：初稿を `work/05_lyrics.txt` に保存し、[check_lyrics_audio.py](scripts/check_lyrics_audio.py) を実行する（スキルフォルダの `scripts/` を指定する）。VOICEVOX Engine を使わない場合は `--offline` をつける。
     ```bash
     python <スキルフォルダ>/scripts/check_lyrics_audio.py --offline work/05_lyrics.txt
     ```
     - 生成された `work/audio-check.md` を確認し、**警告（長すぎ・極短・拍突出・座標語・多音字・禁止記号）・セクション対称性・語彙の反復**が解消するまで歌詞を修正して再実行する（確定後 `work/lyrics.txt` にコピー）。
     - VOICEVOX Engine（`http://127.0.0.1:50021`）が起動していれば `--offline` なしで実行し、実読み上げ（`preview.wav`・OpenJTalk 精密モーラ）でも確認する。

### ⑥ 編曲家 → `work/06_styles.md`（および `work/style.txt`、有料時は `exclude.txt`, `settings.txt`）
③の `z` 変動範囲と⑤の確定歌詞をすり合わせて Suno 向けに調律する（必要に応じて `../genStyle/SKILL.md` を参照）。

- **Style of Music（25語以内）**：先頭に重みが集中するため **「ジャンル → 声質 → コア楽器（3〜4点） → BPM → 全体質感」** の順に並べる。
- **避ける語**：`Fragile`（音圧低下）、`Lush Voicings`（濁り）。静と動の落差には `Dynamic Contrast` を使う。
- **Exclude Styles（有料プラン時）**：2〜3個に絞る（例：`synth, auto-tune, screaming`）。
- **推奨パラメータ（有料プラン時）**：Style Influence `65〜75%`（対比曲 `80%`）、Weirdness `30%` 前後（170 BPM 超は `25〜35%`）。

## ⑦ タイトル・カバー画像・整理（最終ステップ）

1. **タイトル命名 ＆ 一貫性チェック**：余韻の残るタイトルを決め、核イメージが1番〜サビすべてと繋がっているか確認して `work/title.txt` に保存する。
2. **カバー画像生成（`cover.jpg`）**：タイトル・コンセプト・曲の空気感を反映したジャケット画像（文字・ロゴなし）を、`cf-image` MCP（`generate_image`、英語プロンプト・`steps: 4`）で曲フォルダ直下に `cover.jpg` として 1 枚生成する（ユーザーが不要と指定した場合のみ省略）。
3. **貼り付けファイル生成 ＆ フォルダ整理（`songs/<曲名>/`）**：
   - **`work/` サブフォルダ**：`title.txt`, `style.txt`, `lyrics.txt`（有料時は `exclude.txt`, `settings.txt`）、`01_delivery.md` 〜 `06_styles.md`、`audio-check.md` 等を保存する。
   - **貼り付け用ファイル生成**：[generate_paste.py](scripts/generate_paste.py) を実行（`python <スキルフォルダ>/scripts/generate_paste.py "songs/<曲名>"`）し、ルート直下に **`suno-paste.md`** と **`suno-paste.html`**（コピーボタン付き）を生成する（上から **Lyrics → Style of Music → Title** の順）。
   - **ルート直下（貼り付け用・ジャケットのみ）**：`suno-paste.md`、`suno-paste.html`、`cover.jpg`
4. **完了報告**：まず **[`suno-paste.html`](suno-paste.html) へのクリック可能なリンク（`file://`）とフォルダを開くコマンドを提示**し、仕上げのブラッシュアップとして **`/song-review`** を提案する。

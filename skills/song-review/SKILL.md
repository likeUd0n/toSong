# 楽曲・歌詞マルチペルソナレビュー（song-review）

作曲家・作詞家・AI作曲家（Suno専門家）の3人を、具体的な経歴と美学を持つ架空の人物としてサブエージェントで並列起動し、独立した視点からレビュー・改善する。

## 手順

### 0. 対象ファイルの確認
対象となる曲フォルダから以下を読み込む（不足があればあるものだけで進める）：
- 歌詞（`suno-paste.md`、`work/lyrics.txt`、`lyrics.txt` または `<曲名>.txt`）
- スタイル（`work/styles.txt`、`suno-paste.md` または `styles.txt` / `style.txt`）
- ペルソナ（`work/ペルソナ.md` または `ペルソナ.md`）
- 共通メソッド：`../toSong/references/Suno作曲メソッド.md`
- 利用プラン：`~/.config/toSong/preferences.json`（未設定時は有料/無料のファイル構成に合わせる）

### 1. 3人のペルソナ生成と並列レビュー（`invoke_subagent`）
`research` サブエージェントを **3つ同時に並列起動** し、互いの結果を渡さず独立してレビューさせる。

**共通プロンプト指示**：
1. レビュー前に自分のペルソナを3〜5行で具体化する（名前・年齢・キャリア / 偏愛表現 / 許さないNG / 口ぐせ）。
2. 抽象的な感想は禁止。必ず **「該当箇所の引用 → 理由 → 具体的な改善案」** の3点セットで **最低3つ** 指摘する。
3. 担当外の領域には踏み込まない。

**担当別の観点とモデル**：
1. **作曲家（`Model: "inherit"`）**：譜割り、セクション間の繋がり、Bメロの引き算とV字コントラスト（1サビがBメロに負けていないか）、2行刻み・空白によるリズム、楽器の過不足。
2. **作詞家（`Model: "inherit"`）**：舞台と伏線回収（1番→2番→サビ末尾）、コア名詞（3〜5個）の関係値、直訳語や主語落ちの回避、感情トーンの一貫性とCメロ味変、母音ライム。
3. **AI作曲家 / Suno専門家（`Model: "flash"`）**：Style of Music の語順（先頭20〜25語）・競合タグ・有害語、Exclude Styles の絞り込み、メタタグの有効性、漢字・略語の誤読リスク。

### 2. 指摘の統合と `work/review.md` の保存
矛盾がないか整理し、`work/review.md` に「3人のペルソナ」「指摘一覧表（担当 / 該当箇所 / 指摘 / 採用方針）」「普遍的な教訓メモ」を保存する。

### 3. 改善版の作成・`suno-paste.md` 再生成・フォルダ整理
1. **旧版の退避**：レビュー前の歌詞・スタイルを `work/lyrics_v1.txt`・`work/styles_v1.txt` に退避する。
2. **改善版の反映と `suno-paste.md` / `suno-paste.html` 再生成**：改善版を `work/` 配下の最新ファイル（`work/lyrics.txt`, `work/style.txt`, `work/styles.txt` 等）に反映し、`../toSong/scripts/generate_paste.py` を実行してルート直下の `suno-paste.md` と `suno-paste.html`（Lyrics → Style of Music → Title 順・コピーボタン付き）を再生成する。
   - **ルート直下**：`suno-paste.md`、`suno-paste.html` と `cover.jpg`（ある場合）だけを置く。
   - **`work/`**：単体テキスト（`title.txt`, `style.txt`, `lyrics.txt`、有料時は `exclude.txt`, `settings.txt` も）・中間資料・旧版・`review.md` をまとめる。

### 4. `Suno作曲メソッド.md` の更新（最小限・シンプルに）
今後の曲作りでも本当に効く**普遍的な原則だけ**を抽出し、1行で言い切れるシンプルな表現で追記する（細かなルールを増やしすぎない。既存ルールと重複するものは統合する）。

### 5. 完了報告
再生成した **`suno-paste.html` へのクリック可能なリンク（`file://`）を提示してブラウザで開くよう誘導**したうえで、`work/review.md` へのリンク、主な指摘と改善点、`Suno作曲メソッド.md` への追加内容を簡潔に報告する。

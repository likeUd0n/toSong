# AIチャット要約（デモ用・再構成）

## テーマ
大事な予定（試験）の前夜〜当日にかけて、「やるべき」と頭では分かっているのに動けず、散歩や寄り道でどうにか自分の機嫌とバランスを取ろうとする等身大の迷い。

## チャットのやり取り（要約・再構成）

- **【夜】集中が切れて、つい逃げてしまう**
  - 作業を詰め込んでいたら結局集中力が切れた。明日は朝から大事な試験がある。
  - 「少し外の空気を吸って散歩しようかな」と思いつつ、玄関を出るハードルが高くて、ついゲームをもう1戦だけ始めてしまう。よくない試合に当たって、余計にどっと疲れる。
- **【深夜】外に出てみるが、「何か取り返さないと」と焦る**
  - 胃のあたりが重い。「一度外に出てから考えよう」と、ようやく夜道へ歩き出す。少し遠くまで歩く。
  - 帰り道、ファストフード店で甘いチョコパイとコーヒーを頼んでしまう。美味しいけれど、こんな時間にコーヒーを飲んでしまったし、何か（無駄にした時間や充実感）を取り返さないとという焦りがあって、素直に家に帰るモチベーションが湧かない。
- **【朝】「行けないわけではない。行きたくない」**
  - 睡眠時間は3時間半くらい。試験の時間、正確には**起きていたけれど、起きれなかった**。
  - 別にすごく辛いわけではない。ただ、片道1時間半かけて会場へ向かうことを想像すると、急に体が重くなる。
  - 「行けないわけではない。行きたくないんだ」と気づいて、とりあえずもう一度起き上がってから考えようと思う。

# 戯曲・MV台本（ステップ3：【実験】）

- **抽選モチーフ**：`大きな窓がある部屋` / `机の端に積まれた数冊の本と奥の木箱`
- **時間軸**：深夜（ゲーム中断 → 散歩 → ファストフードの帰り道）→ 翌朝（試験当日の朝）

---

### シーン1：深夜1時・大きな窓がある部屋
- `[映像 / カメラ]`：モニターの青白い光に照らされた手元の寄り → パンして、机の端（画面の影になるところ）に無造作に積まれた数冊の参考書と、その奥の木箱。引きの絵で、大きな窓の外に暗い街並み。
- `[音 / 環境]`：マウスのクリック音と、ヘッドセットから漏れるゲームの敗戦ジングル。それが途切れると、エアコンの低い送風音だけになる。
- `[ト書き]`：ヘッドセットを外して机に置く。参考書の背表紙を一瞬だけ見て、目を逸らし、椅子から立ち上がる。ポケットに鍵とスマホを突っ込む。
- `[セリフ / 心の声]`：（小さく息を吐いて）「……あー、一回外でよ」

### シーン2：深夜2時・24時間営業の店の明かりと帰り道
- `[映像 / カメラ]`：オレンジ色のひさしが光るガラス張りの店から出てくるところを、少し離れた歩道から引きで撮る。手元へのインサート：熱いコーヒーの紙カップと、紙袋の中の甘いパイ。足元の横断歩道の白線が街灯でうっすら光っている。
- `[音 / 環境]`：自動ドアの電子音 → 遠ざかる夜間の幹線道路のタイヤ音。足音と、紙袋がカサッと擦れる音。
- `[ト書き]`：歩道の縁石をなぞるようにゆっくり歩く。立ち止まってホットコーヒーをひと口飲み、熱さに少し顔をしかめてから、また歩き出す。家の方角を見やるが、歩幅がなかなか速まらない。
- `[セリフ / 心の声]`：（口の中で）「……こんな時間に飲んじゃったな。ま、いっか」

### シーン3：午前8時半・大きな窓がある部屋（朝）
- `[映像 / カメラ]`：大きな窓のレースカーテン越しに、まぶしい朝日が白いマットレスのシーツのしわに落ちている。スマホの画面が上向きに光っている（アラームは止まっている）。主観ショット（POV）で、横になったまま机の端の本と木箱を見つめる。
- `[音 / 環境]`：エアコンの音は消え、窓の外から遠くの電車の走行音と鳥の声。部屋の中はほぼ無音。
- `[ト書き]`：目は完全に開いているのに、布団から肩を出さない。片手を伸ばしてスマホを裏返し、画面を伏せる。天井を3秒見て、シーツを鼻のあたりまで引き上げる。
- `[セリフ / 心の声]`：（布団の中で籠った声）「行けないわけじゃないんだよな。……行きたくないだけで」

### シーン4：午前9時・窓辺（動き出す前の余白）
- `[映像 / カメラ]`：窓枠の影がベッドの上を少しだけ移動している。主人公がゆっくりと上半身を起こし、マットレスの端に座る。机の上の冷めかけたマグカップと、端の本が視界に入る。
- `[音 / 環境]`：シーツが擦れる音。窓の外を風が通り抜ける音（わずかに窓ガラスが鳴る）。
- `[ト書き]`：膝に肘をついて、窓の外の明るい空をぼんやり見る。まだ靴は履かないし、カバンも持たない。ただ、深呼吸を1回だけする。
- `[セリフ / 心の声]`：（独り言）「……とりあえず、起きてから考えよう」

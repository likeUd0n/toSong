# コンセプト・観客視点・五感設計（ステップ4：【結晶】）

## 1. コンセプトと観客視点
| 項目 | 内容 |
|---|---|
| **曲のコンセプト** | 「やるべきこと」から逃げて深夜に寄り道し、翌朝も「行けないわけじゃない、行きたくないだけ」と布団の中で足踏みする**人間の等身大の弱さ**を、無理にポジティブへ変換せず、そのまま肯定する曲。 |
| **リスナーの初期状態** | 大事な予定や課題を前に足がすくみ、夜更かしや無駄な寄り道をして「またダメだった」と小さな自己嫌悪を抱えている状態。 |
| **リスナーにどうなってほしいか（ゴール）** | 「ちゃんとしていない自分」を責めるのを少しだけ止めて、「まずは起きてから考えよう」と肩の力を抜けるようになる。 |
| **捨てる要素（Not-To-Sing）** | 家族への期待、通院やツールの固有名詞、具体的な地名・学校名、説教くさい教訓（「努力すれば報われる」等）。 |

## 2. 時間軸・周囲の音の流れ・五感の整理
- **時間の進み**：深夜1時（自室でゲーム中断）→ 深夜2時（24時間店の帰り道）→ 午前8時半〜9時（レースカーテン越しの朝・自室）
- **周囲の音の流れ（Soundscape）**：
  - 深夜の部屋（マウス音・ゲームのノイズ・エアコンの低い音） → 深夜の夜道（自動ドアの電子音・遠い車の走行音・自分の足音） → 朝の部屋（遠くの電車と鳥の声・室内はほぼ無音・シーツの擦れる音）
- **視覚・聴覚（ベース）**：
  - 深夜のオレンジ色の店のひさしと暗いアスファルト、翌朝のレースカーテン越しに白く飛ぶ光と窓枠の影。
- **触覚（◎ 必須）**：
  - 夜道の少し冷たい空気、熱い紙カップの熱、朝の冷えたシーツのしわと重み。
- **嗅覚・味覚（○ 1点スパイス）**：
  - 深夜に頼んでしまった**甘いチョコパイと苦いコーヒー**（美味しいのに、どこか後ろめたさが残る味）。

# 戯曲・MV台本（script.md）

### シーン1：マジックアワーの商店街（BAKERY AKARI の前）
- [映像 / カメラ]：パン屋の暖かいオレンジ色のガラス窓からパンアウト。両手にケーキ箱と文房具屋の紙袋を抱えた主人公（白いダッフルコート・赤いマフラー）が、少し小走りでフレームインしてくる。
- [音 / 環境]：商店街の賑やかなBGM、扉が開くカランという鈴の音、遠ざかる笑い声。
- [ト書き]：左の耳元に留めたヘアピンを風で押さえたいのに、両手がふさがっていて肩をすくめる。ケーキ箱が水平になっているかチラッと見下ろす。
- [セリフ / 心の声]：「よし、クリームはまだ無事。あと五分、間に合え！」

### シーン2：点滅する踏切の前（JR 駅と高架電車）
- [映像 / カメラ]：主人公の背越しショット（OTS）。目の前で黄色と黒の遮断機が下り、赤いランプが点滅する。その向こうを電飾のついた高架電車が走り抜け、上空の濃い青に粉雪が舞い始める。
- [音 / 環境]：カンカンカン、と踏切の警告音がリズミカルに鳴り響く。電車が通過する風の音。
- [ト書き]：一瞬「あ、捕まった」と足を止めるが、白い息を吐いて空を見上げた瞬間、雪の粒とイルミネーションが目に入り、思わず口元がほころぶ。
- [セリフ / 心の声]：「急いでるときに限ってこれだもん。……でも、なんか綺麗だな」

### シーン3：横断歩道を渡って、家のドアの前へ
- [映像 / カメラ]：踏切が上がり、点字ブロックの上を軽やかに駆け出す足元のインサート → 玄関のドアを開けると、オレンジ色の暖かい光がカメラいっぱいに溢れる主観ショット（POV）。
- [音 / 環境]：踏切の音が遠ざかり、ドアが開いた瞬間に部屋の中の笑い声、皿の鳴る音、弾けるクラッカーの音が押し寄せる。
- [ト書き]：玄関でコートの雪を軽く払い、少し斜めになった赤いリボンの箱をテーブルの真ん中へ「お待たせ！」と差し出す。
- [セリフ / 心の声]：「ちょっと遅れちゃったけど、主役はちゃんと連れてきたよ！」

### シーン4：テーブルを囲む夜
- [映像 / カメラ]：少し飾りが偏ったミニツリーとケーキ、マグカップを掲げるみんなの笑顔を少し引きの俯瞰で映し、窓の外の雪と街明かりへゆっくりパンアップ。
- [音 / 環境]：グラスとカップの乾杯の音、途切れない笑い声、遠くで優しく鳴るクリスマスベル。
- [ト書き]：冷えた指先をマグカップで温めながら、文房具屋の紙袋からまだ白紙のカードを笑いながら取り出す。
- [セリフ / 心の声]：「言葉はあとでいいや。メリークリスマス！」

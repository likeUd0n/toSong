# ワード・マイニング ＆ 自由詩（poetry.md）

## 1. ワード・マイニング
- **モノのコア名詞（4個）**：ケーキの箱（赤いリボン）、赤いマフラー、紙袋（白いカード）、踏切（遮断機）
- **環境の時計（3個）**：マジックアワーの商店街、舞い降りる粉雪、暖かい部屋のオレンジの灯り

## 2. 感情フィルター（知覚の反転）
| モチーフ / 五感 | 焦り・小走り時（1番・A〜Bメロ） | 解放・合流時（サビ・ラスサビ） |
|---|---|---|
| **赤い踏切と遮断機** | 急いでいるのに足止めしてくる、ちょっと意地悪な時計。 | 粉雪とイルミネーションを見上げるための、特別なひと休み。 |
| **ケーキの箱と紙袋** | 両手をふさいで、崩さないかヒヤヒヤする重い荷物。 | みんなの笑顔の真ん中へ運ぶ、今日いちばんの主役。 |
| **12月の冷たい風** | 頬を刺して、ヘアピンごと前髪を乱す慌ただしい風。 | 部屋のドアを開けた瞬間の、暖かさを引き立てるスパイス。 |

## 3. 自由詩（制約なしで書く）
パン屋のガラスからこぼれるオレンジの光
焼き立てのバターの甘さを背中に受けて
白いダッフルの袖を揺らしながら わたしは少し早足になる

右手のケーキ箱 水平をキープして
左手には文房具屋で選んだ紙袋
まだ白紙のままのカードが 袋の底でカサリと笑う

赤いマフラーの端が頬に当たって
冷たい風が耳元のヘアピンを揺らすけど
両手がふさがっているから まあいっかと肩をすくめた

駅前の踏切が カンカンと鳴って降りてくる
ちょっと待ってよ あと五分なのに
そう呟いて顔を上げたら
濃い青の空から 白い粉雪が電飾に絡まって降ってきた

夕焼けのピンクが溶けた街の真ん中で
高架の電車が光の帯になって過ぎていく
急ぐ理由なんて みんなを笑わせたいだけだったのに
待っている時間まで キラキラして見えた

遮断機が上がったら 点字ブロックを軽やかに跳ねて
ドアを開ければ 一瞬で溶ける頬の冷たさ
傾いたミニツリーも 白紙のカードも そのままテーブルに並べて
せーので鳴らすマグカップ

完璧な聖夜じゃなくていい
赤いリボンがちょっとほどけかけても
今夜のわたしたちがいちばん暖かいから
せーので笑おう メリークリスマス

# ワード・マイニング ＆ 自由詩（poetry.md）

## 1. ワード・マイニング
- **モノのコア名詞（4個）**：白いスニーカー、捲った水色のシャツ、塀の上の猫、パン屋の匂い
- **環境の時計（3個）**：木漏れ日の坂道、二股の路地、光が揺れる川沿いの風

## 2. 感情フィルター（知覚の反転）
| モチーフ / 五感 | 歩き出し・考えごと名残（1番・Aメロ） | 解放・川沿いの爽快感（サビ・ラスサビ） |
|---|---|---|
| **スマホと予定表** | 昨日まで頭の中を占領していた、通知の赤いバッジ。 | ポケットの奥にしまい込んで、今日だけは置いていくもの。 |
| **街角の交差点・二股** | どちらを選べば正しいのか迷いがちな分岐点。 | どっちに曲がってもパンの匂いと光が待っている自由な道。 |
| **朝の空気と風** | 寝不足の頭を少しだけ醒ます、ひんやりした外気。 | 捲った腕と頬を通り抜けて、胸いっぱいに広がる味方。 |

## 3. 自由詩（制約なしで書く）
玄関のドアが閉まる軽い音
白のスニーカーが乾いたアスファルトを叩く
水色のシャツの袖を無造作に捲って
ジーンズの裾をひと折りしたら もうオフの合図

左手をポケットに突っ込んで
通知を切ったスマホは奥へしまったまま
木漏れ日の葉っぱの影を踏まないように
なんて小さな遊びをしながら坂を下る

二股に分かれた角のオレンジのテント
ひだまりベーカリーから風に乗って届く
焼きたての小麦と甘いバターの香り
それだけで昨日のモヤモヤが半分くらい溶けていく

ブロック塀の上 茶トラと白の猫が二匹
日向ぼっこしながら ぼくのほうをちらりと見る
「お前も今日 予定なしか」
心の中で挨拶して 自転車のベルを見送る

狭い路地を抜けた瞬間 視界がぱっと開けた
澄んだ青空と キラキラ跳ねる川面の光
頬を撫でる爽やかな川風に深呼吸をひとつ
答えなんて急いで決めなくていい

歩くリズムがそのままメロディになる
ポケットは空っぽのまま でも心はちょっと軽い
このまま川沿いをもう少しだけ 気の向くほうへ

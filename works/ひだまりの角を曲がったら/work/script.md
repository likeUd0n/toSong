# 戯曲・MV台本（script.md）

### シーン1：木漏れ日の住宅街（玄関を出て坂道へ）
- [映像 / カメラ]：白いスニーカーが玄関の敷居を跨ぐ足元のアップ → 引きの絵になり、淡い水色のシャツの袖を無造作に捲りながら坂道を歩き出す主人公。地面には木々の葉の影がくっきり落ちている。
- [音 / 環境]：玄関のドアが閉まる軽い音、乾いたアスファルトを踏むスニーカーの一定のリズム、街路樹の葉が揺れる音。
- [ト書き]：スマホをポケットの奥にしまい込み、空の青さを見て軽く首を回す。左手をポケットに入れたまま、少しだけ歩幅を広げる。
- [セリフ / 心の声]：「通知はオフ。今日はどっちの角を曲がっても正解ってことにしよう」

### シーン2：ひだまりベーカリーと塀の上の猫
- [映像 / カメラ]：二股に分かれた道の正面、「ひだまりベーカリー」のオレンジ色のテントが映る。奥から自転車がチリンと通り過ぎ、カメラが右へ振れるとブロック塀の上で日向ぼっこする2匹の猫のアップ。
- [音 / 環境]：自転車のベルとタイヤの回転音、遠くで鳥のさえずり、パン屋のドアが開く気配。
- [ト書き]：ふわりと流れてきた香りにつられて足を緩め、塀の上の茶トラの猫と目が合うと、少しだけ口角を上げて小さく会釈する。
- [セリフ / 心の声]：「あ、いい匂い。……お前も今日、予定なしか」

### シーン3：川沿いの遊歩道（光が開ける昼下がり）
- [映像 / カメラ]：住宅街の狭い路地を抜けた瞬間、視界が一気に開けて青い空と白い雲、太陽を反射してキラキラ光る川面が広がる主観ショット（POV）。
- [音 / 環境]：生活音が遠ざかり、川を吹き抜ける爽やかな風の音と、遠くの橋を渡る電車の軽やかな音。
- [ト書き]：橋の手すりに軽く手を置き、大きく息を吸い込んでから、ロールアップした裾を揺らしながら川沿いの道へ再び歩き出す。
- [セリフ / 心の声]：「風、気持ちいいな。昨日まで何に焦ってたんだっけ」

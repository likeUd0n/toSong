# 戯曲・MV台本（ステップ 3）

- **核テーマ**：3コマ目（最終コマ）で日常が反転する瞬間
- **抽選モチーフ**：A「椅子」 / B「ドアノブ」

---

### シーン1：1コマ目（静かな待機）
- `[映像 / カメラ]`：部屋の真ん中にぽつんと置かれた木製の椅子。少し引いた固定カメラ。夕方前の平穏な空気。
- `[音 / 環境]`：遠くを走る車の低い唸り、時計の秒針のような一定のリズム。
- `[ト書き]`：主人公は木製の椅子に深く腰掛け、両手を膝の上に揃えて置いている。つま先が床をトントンと小さく叩く。
- `[セリフ / 心の声]`：（静かに、言い聞かせるように）「……よし。今日も、いつも通りだ」

### シーン2：2コマ目（高まる緊張と準備）
- `[映像 / カメラ]`：椅子に座る主人公の手元と横顔へのクローズアップ。少し角度が傾き、呼吸に合わせて画面がわずかに揺れる。
- `[音 / 環境]`：環境の音が遠のき、心臓の鼓動のような低いバス音と、衣擦れの音だけが大きくなる。
- `[ト書き]`：主人公が椅子から腰をわずかに浮かせ、背筋をピンと伸ばし直す。喉を鳴らし、入り口の方角をまっすぐ見据える。
- `[セリフ / 心の声]`：「足音はもうすぐそこだ。深呼吸して、笑顔を作って、一気に決めるんだ」

### シーン3：3コマ目（最終コマ・反転）
- `[映像 / カメラ]`：入り口の壁際、冷たい金属製のドアノブへの超クローズアップ。→ ドアノブがカチャリと回った瞬間、カメラが一気に引き（ワイドショット）、部屋の全貌と主人公を映す。
- `[音 / 環境]`：鼓動の音がプツリと止まり（無音）、カチャリという金属音だけが乾いて響く。その後、拍子抜けするほど軽やかな生活音。
- `[ト書き]`：入り口から見知らぬ住人が買い物袋を提げて入ってくる。主人公は完璧な姿勢のまま固まり、住人もまた靴を片方脱ぎかけたまま固まる。
- `[セリフ / 心の声]`：住人「……えっと、どちら様ですか？」 / 主人公（心の声）「……あれ、ここ、三階じゃなくて二階だ」

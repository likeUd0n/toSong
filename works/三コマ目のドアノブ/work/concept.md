# コンセプト設計（ステップ 4：`concept.md`）

## 1. 曲のコンセプト
1〜2コマ目で深刻そうに構えていた日常の緊張が、3コマ目の「ドアノブが回る音」ひとつで、実は見当違いの勘違い（部屋間違い）だったとひっくり返る、小気味よく軽やかな反転ポップ。

## 2. リスナーの変化
- **初期状態**：何か大事な勝負や告白、面接の前のような、主人公の「そわそわした緊張感」に付き合わされている。
- **聴き終えたあと**：肩の力が抜けてクスッと笑い、「深刻に構えすぎていたけど、だいたいそんなものだよな」と少し身軽になる。

## 3. 捨てる要素（Not-To-Sing）
- 教訓めいたまとめ（「人生とは思い込みだ」等の説教）
- 本当に怖いホラーやサスペンスへの着地（あくまで笑える日常のズレに留める）
- ステップ2の未選要素（窓辺、机、本棚、廊下、ドア、チェスト、マグカップ、紙切れ、カーテン、張り紙、文庫本、壁掛け鏡、小皿）

## 4. 時間軸・音の流れ・五感
- **時間軸**：夕方前の少し傾いた時間（待機） → 鼓動が高まる直前 → 金属音が響く無音の1秒 → 拍子抜けする明るい日常。
- **音の流れ**：時計の秒針のようなスタッカート（Aメロ） → 鼓動と息遣い（Bメロ） → 完全に無音になる一瞬のブレイク → 跳ねる軽快なビートとホーンで肩透かし（サビ）。
- **五感**：
  - **触覚（必須）**：硬い木製の椅子の座面、膝の上で汗ばむ手のひら、そして入り口の冷たい金属のドアノブ。
  - **嗅覚（スパイス）**：ドアノブが回って空気が動いた瞬間、ふわりと鼻をかすめる「自分の家とは違う柔軟剤の匂い」。

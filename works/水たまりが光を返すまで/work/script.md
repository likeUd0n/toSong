# 戯曲・MV台本（script.md）

> 歌の構成（1番・2番・サビ）はいったん忘れ、3〜4シーンの一幕劇として書く。

## シーン1：昼の高架下（外に見せる自分／音の飽和）
- `[映像 / カメラ]`：【引き】黄色いイチョウとコートの人波の中、グレーのパーカー1枚で立つ背中 → 【インサート】雨上がりの水たまりに映る歪んだビル → 【主観POV】下から見上げる高架橋。
- `[音 / 環境]`：頭上を走る電車の轟音、車のエンジン音、信号の電子音、行き交うスニーカーと革靴の足音が飽和している。
- `[ト書き]`：知り合いに会ったように軽く片手を上げて笑って見せる。すれ違った直後、冷えた指先を隠すようにポケットの奥へ両手を押し込む。
- `[セリフ / 心の声]`：「大丈夫、最近いい感じ」／（すれ違いざま、心の声）「……嘘。足元すら見れてない」

## シーン2：夕方の駅のホーム（境界／音の引き算）
- `[映像 / カメラ]`：【インサート】暮れていく空と電線に止まる鳥の影 → 【寄り】発車していく電車を見送るスニーカーの先。
- `[音 / 環境]`：電車のドアが閉まり、街のざわめきが遠ざかる。遠くの踏切の音と、ベンチに座り直す音だけが残る。
- `[ト書き]`：目の前の電車に乗らず、用もないのにしゃがんで靴紐を結び直すフリをする。
- `[セリフ / 心の声]`：「もう1本あとでいいや」

## シーン3：深夜1時半の部屋（内側の本音／極限の静寂）
- `[映像 / カメラ]`：【主観POV】電気を消した暗い部屋、親指の上で青白く光るスマホ画面 → 【インサート】白いままのノートの角、湯気の消えたカップ。
- `[音 / 環境]`：外の車も止んだ無音。親指がガラスを滑る小さな摩擦音と、時計の秒針だけ。
- `[ト書き]`：誰かの「うまくいっている報告」を閉じてはまた開き、小さく息を吐いてスマホを下向きに机へ伏せる。
- `[セリフ / 心の声]`：（声に出さず、息だけ）「ちゃんと歩けてるのかな」

## シーン4：画面を伏せた数秒後（視界の切り替え／回復）
- `[映像 / カメラ]`：スマホを伏せた直後の暗がり → ゆっくり目が慣れ、窓の外の街灯が机の輪郭を戻す → 【インサート】夜風に揺れる前髪と、流し台へ運ばれる冷めたカップ。
- `[音 / 環境]`：スマホを伏せた「カチッ」という乾いた音のあと、1拍の完全な無音 → 窓の隙間から遠い夜風と、自分の呼吸音だけが戻ってくる。
- `[ト書き]`：冷めきったカップを持ち上げ、一口だけ残りを飲んで少し眉をしかめる。そのまま立ち上がり、流し台へ向かって歩き出す。
- `[セリフ / 心の声]`：「……苦っ。まあ、今日はこれでいい」

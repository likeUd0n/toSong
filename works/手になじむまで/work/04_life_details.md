# ④ 象徴・温度変化メモ（苗木・情景型）

## 守る制約（元指示書より固定）
- **やらないこと**：
  - 悲しみを安易に克服・解決・肯定する展開
  - 励ましや自己啓発的なメッセージ（「大丈夫」「明日は晴れる」「前を向こう」等）
  - 過度にドラマチックな感情表現・悲劇的すぎる演出
  - 明るさや希望を強制する結末
  - 誰かを責める／結論を押しつける表現
  - 特定個人の事情（職業・スマホ通知・具体的な事件）への過剰な限定
  - 劇的な盛り上がりや唐突な転調（`[Key Change]` `[Belted Vocals]` `[Peak Intensity]` 等は使わない）
- **守る温度感・抽象度**：
  - 内省的で繊細な言葉。感情を直接説明しすぎず、風景や日常の小さな手触りを通して描く。
  - 過去の自分と現在の自分の距離が、少しずつ変化していく感覚。
  - 冒頭のフレーズ・メロディを終盤に再び登場させ、最初とは違って聴こえるようにする。

## 核となる象徴・比喩（2つに絞る）
1. **ふたつの影／並ぶ歩幅**
   - 答えを持たないまま隣を歩く気配の象徴。
   - 時間が経つにつれ、影の長さや傾き、足元の光が少しずつ変わっていく。
2. **ポケットのなかの重み（名前をつけずに持ったまま歩くもの）**
   - 悩みや悲しみを「捨てる」「解く」のではなく、手放さないまま季節をまたぐ象徴。
   - 最初は冷たく重かったものが、いつの間にか手のひらに馴染んで、重さの輪郭が変わっている。

## セクションごとの温度変化（5段階構成）
1. **冒頭（Intro / Verse 1）**：曖昧で静かな悲しみ。音数を極力絞る（`[Piano Only]`）。輪郭の定まらない曇り空や夕暮れ前の気配。答えの出ないまま立ち止まる温度。
2. **展開（Verse 2 / Chorus 1）**：小さなリズムや柔らかなシンセが加わり、ゆっくり歩き始める。急がず、並んだ歩幅とポケットの重みをそのまま受け入れる。
3. **中盤（Verse 3 / Chorus 2）**：和声と音色がわずかに開き、景色が移ろう。期待と失望のあいだを通り過ぎた記憶、少し遠くなった昨日の輪郭。
4. **終盤（Bridge）**：穏やかな受容。転調も絶叫もせず、立ち止まっていた頃の自分を少し離れた場所から静かに眺める温度。
5. **終わり（Final Chorus / Outro）**：冒頭と同じメロディ・同じ言葉の響きが戻る。しかし歩いた時間のぶんだけ、重みは「痛み」ではなく「暮らしの一部」として静かに馴染んでいる。

## z（音源）の変動範囲（⑥編曲家向け・⑤へは渡さない）
- **テンポ**：74〜78 BPM（ゆっくり、急がない歩幅）
- **コア楽器**：柔らかいフェルトピアノ、温かみのあるアナログシンセパッド、繊細なアンビエントテクスチャ、中盤から控えめなブラシ系パーカッション
- **和声と展開**：曖昧さや未解決感を残す浮遊感のある和声（sus2 / maj7 系）。音数は少なめから入り、少しずつ温かさと厚みを足す。劇的な盛り上がり・転調は避ける。
- **声質**：親密で穏やかなウィスパー〜ソフトボーカル（`Intimate Soft Female Vocals`、`Fragile` は使わない）。
- **結び**：冒頭のピアノモチーフがアウトロで温かく反復して静かに終わる。
